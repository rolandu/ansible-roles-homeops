# wireguard_client

Install a generated native WireGuard client configuration on an actual client
host.

**This is an administrative role and it assumes privileged execution (`become: true`) works on the target host.**

## Responsibilities

This role:

- installs WireGuard client packages
- copies one generated client `.conf` from the Ansible controller
- writes `/etc/wireguard/{{ wireguard_interface }}.conf`
- enables and starts `wg-quick@{{ wireguard_interface }}`

This role does **not**:

- generate keys
- generate client configs
- configure the WireGuard server
- configure firewall rules
- configure NAT

The `wireguard_server` role generates peer keys and client configs on the VPN
server, then fetches those generated configs to the controller under:

```text
{{ artifacts_dir }}/wireguard-clients/{{ wireguard_network_name }}/
```

## Variables

- `wireguard_interface` (default: `wg0`): local WireGuard interface and systemd instance name.
- `wireguard_network_name` (default: `home`): network subdirectory under the controller artifact path.
- `wireguard_client_name` (default: `{{ inventory_hostname }}`): peer name to install. Must match a peer generated by `wireguard_server`.
- `wireguard_config_dir` (default: `/etc/wireguard`): target config directory.
- `wireguard_client_config_file` (default: `{{ wireguard_config_dir }}/{{ wireguard_interface }}.conf`): target config file.
- `artifacts_dir` (default: `{{ inventory_dir }}/artifacts`): controller artifact base path.
- `wireguard_client_local_dir_base` (default: `{{ artifacts_dir }}/wireguard-clients`): controller WireGuard artifact base.
- `wireguard_client_local_dir` (default: `{{ wireguard_client_local_dir_base }}/{{ wireguard_network_name }}`): controller directory containing fetched configs.
- `wireguard_client_source_config` (default: `{{ wireguard_client_local_dir }}/{{ wireguard_client_name }}.conf`): controller-side config to install.
- `wireguard_client_manage_service` (default: `true`): enable/start/restart `wg-quick@<interface>`.
- `wireguard_client_packages` (default: `wireguard`, `wireguard-tools`): packages installed on Debian-family clients.
- `wireguard_client_dns_helper_packages` (default: `[]`): optional resolver helper packages, for example `resolvconf` or `openresolv`.

## Example

Server play:

```yaml
---
- name: Configure WireGuard server and export clients
  hosts: vpn
  become: true

  roles:
    - role: wireguard_server
```

Client play:

```yaml
---
- name: Install WireGuard client config
  hosts: laptop
  become: true

  roles:
    - role: wireguard_client
```

Client vars:

```yaml
wireguard_interface: wg0
wireguard_network_name: home

# Must match the peer name in wireguard_server's wireguard_peers list.
wireguard_client_name: laptop

# Optional, if the generated config contains DNS= and wg-quick needs a helper.
wireguard_client_dns_helper_packages:
  - resolvconf
```

## DNS note

Generated configs may contain a `DNS = ...` line. The WireGuard config format
does not enforce resolver priority by itself; the local client tooling applies
it. On Linux with `wg-quick`, DNS handling commonly requires a `resolvconf`
compatible helper. If DNS is not applied on a client, install an appropriate
helper package using `wireguard_client_dns_helper_packages`.

## Verification

On the client:

```bash
sudo systemctl status wg-quick@wg0
sudo wg show
ip address show wg0
```

## Security note

The generated client config contains the peer private key. The installed target
file is root-owned with mode `0600`; protect the controller-side artifact path
the same way.
